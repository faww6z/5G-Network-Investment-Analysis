# Design provenance

Template selected online and downloaded for inspection on 21 November 2026:

[Financial Management for Small Businesses Consulting](https://www.slidescarnival.com/template/financial-management-for-small-businesses-consulting/155244), SlidesCarnival / Canva.

The downloaded reference uses a 16:9 canvas, ink `#151515`, lime `#D8FB50`, white, and Alata text. This project adapts its split editorial composition, strong grid alignment and restrained lime highlights. It uses Arial/Helvetica for portable editable financial content, replaces all template copy, and substitutes native financial charts and tables for the template's stock photos and illustrations. The resulting deck is an adaptation, not an unchanged template or an endorsement by SlidesCarnival.

The report, workbook and Python charts use the same palette. Working Excel inputs keep standard blue editable-input and green cross-sheet formula conventions. Data charts show actual model values without decorative 3D effects.
